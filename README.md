# Exploratory Data Analysis (EDA) on Sales Dataset

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a sales and customer transactions dataset stored in Microsoft Excel. The goal is to understand the structure of the data, identify patterns, detect anomalies, and generate business insights that can support data-driven decision-making.

---

## Dataset Information

**File Format:** Excel (.xlsx)

**Number of Records:** 1,200

**Key Fields:**

* OrderID
* Date
* CustomerID
* Product
* Quantity
* UnitPrice
* PaymentMethod
* OrderStatus
* CouponCode
* ReferralSource
* ItemsInCart
* TotalPrice

---

## Objectives

The analysis aims to:

* Understand the distribution of sales data
* Calculate descriptive statistics
* Identify trends and patterns
* Detect outliers and unusual transactions
* Evaluate product performance
* Analyze customer purchasing behavior
* Generate actionable business recommendations

---

## Analysis Performed

### 1. Data Cleaning

* Checked for missing values
* Identified unnecessary columns
* Validated data consistency

### 2. Descriptive Statistics

Calculated:

* Count
* Mean
* Median
* Minimum values
* Maximum values

For:

* Quantity
* Unit Price
* Items in Cart
* Total Price

### 3. Trend Analysis

Analyzed:

* Product sales performance
* Payment method preferences
* Order status distribution
* Referral source effectiveness

### 4. Outlier Detection

Investigated:

* High-value transactions
* Unusual purchasing behavior
* Extreme TotalPrice values

---

## Key Findings

### Sales Insights

* High-priced electronic products generated the largest revenue.
* Average order value exceeded ₦1,000 equivalent units in the dataset.

### Customer Behavior

* Digital payment methods were the most frequently used.
* Social media channels contributed significantly to customer acquisition.

### Operational Insights

* Most orders were successfully delivered or shipped.
* Only a small percentage were cancelled or returned.

### Outliers

* Several transactions had exceptionally high order values.
* These orders may represent premium customers or bulk purchases.

---

## Recommendations

### Business Recommendations

* Increase marketing investment in top-performing products.
* Expand customer referral programs.
* Improve return and cancellation management processes.
* Develop loyalty programs for high-value customers.

### Data Recommendations

* Remove unused columns.
* Standardize missing coupon information.
* Build dashboards for continuous monitoring.
